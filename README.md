# Zomato Data Analysis Project

## 📌 Overview
This project involves an end-to-end data analysis of Zomato restaurant data to extract actionable business insights. The analysis focuses on understanding customer preferences, pricing patterns, restaurant performance, and service adoption trends using SQL, Excel, Power BI, and Tableau.

---

## 🎯 Objectives
- Perform data cleaning and transformation on raw restaurant data
- Conduct exploratory data analysis (EDA) on key attributes
- Generate business insights on ratings, pricing, and cuisines
- Build interactive dashboards for decision-making

---

## 📊 Key Analysis Performed

### 1. Data Cleaning & Preparation
- Handled missing and inconsistent data
- Standardized columns such as ratings, price range, and location
- Prepared dataset for analysis using Excel and SQL

### 2. Exploratory Data Analysis (EDA)
- Analyzed restaurant ratings distribution
- Identified popular cuisines across regions
- Examined pricing patterns across different cities

### 3. SQL-Based KPI Analysis
Developed SQL queries to calculate:
- Restaurant distribution by city and country
- Rating segmentation (high, average, low-rated restaurants)
- Price bucket analysis
- Service adoption rates:
  - Online Delivery
  - Table Booking

### 4. Data Visualization & Dashboards
- Built interactive dashboards using Power BI and Tableau
- Visualized:
  - Top-performing cities
  - Cuisine popularity trends
  - Pricing vs rating relationships
- Enabled easy interpretation of business insights

## 📈 Key Insights
- Certain cities dominate in restaurant density and customer engagement
- Mid-range pricing categories show higher customer preference
- Popular cuisines vary significantly by region
- Online delivery adoption is higher compared to table booking

---

## 💡 Business Impact
The analysis helps:
- Identify high-demand locations for expansion
- Optimize pricing strategies
- Understand customer preferences
- Improve service offerings like delivery and booking
